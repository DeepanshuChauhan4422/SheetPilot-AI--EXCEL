# 🤖 SheetPilot AI

SheetPilot AI is an AI-powered Excel Assistant that allows users to control and analyze Excel spreadsheets using natural language.

Instead of manually performing Excel operations, users can simply ask the AI to read, write, update, format, sort, calculate, and create charts in Excel.

## 🚀 Features

- 📖 Read Excel ranges using natural language
- ✏️ Update individual Excel cells
- 📝 Write data into Excel ranges
- 🧹 Clear Excel ranges
- 🧮 Add Excel formulas
- 🎨 Format Excel cells and ranges
- 🔽 Sort Excel data
- 📊 Create Excel charts
- 🤖 AI-powered natural language interaction
- ⚡ FastAPI backend
- 🔗 Excel Add-in integration
